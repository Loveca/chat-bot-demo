# Chatbot Demo 需求说明

版本：v0.2  
更新日期：2026-05-19

## 目标

构建一个可本地运行的 Web 聊天 Demo：界面参考 Claude 的基础聊天结构，后端通过 DeepSeek API 提供对话能力。项目用于学习、演示，或作为更完整聊天产品的前端壳层。

## 核心需求

### 对话能力

- 用户可以输入文本并发送。
- 支持多轮对话，当前会话历史会作为上下文发送给服务端。
- 支持 SSE 流式输出。
- 支持停止正在进行的生成。
- API Key 只能在服务端环境变量中读取，不能暴露给前端。

### 会话管理

- 支持新建空白会话。
- 侧边栏展示历史会话列表。
- 支持切换会话。
- 会话数据持久化到浏览器 `localStorage`。
- 默认使用首条用户消息生成会话标题。

### 消息展示

- 用户消息和助手消息使用不同视觉样式。
- 助手消息支持 Markdown 和 GFM。
- 代码块支持语法高亮、语言标识和复制。
- 流式输出期间显示光标。
- 错误和停止状态需要有明确提示。

### 配置

- `DEEPSEEK_API_KEY`：必填，服务端 DeepSeek Key。
- `DEEPSEEK_BASE_URL`：可选，默认 `https://api.deepseek.com`。
- `DEEPSEEK_DEFAULT_MODEL`：可选，默认 `deepseek-chat`。
- `SYSTEM_PROMPT`：可选，服务端注入的系统提示词。
- `MAX_HISTORY_MESSAGES`：可选，发送给模型的最大历史消息数。

## 非目标

首版不包含账号体系、计费、多租户、文件上传、联网搜索、分享链接和团队空间。

## MVP 验收标准

- 配置 `.env.local` 后，可以在浏览器完成多轮对话。
- 助手回复以流式方式显示，并可点击停止。
- 刷新页面后，会话列表与消息仍存在。
- 代码块可以渲染并复制。
- 前端请求中不携带 DeepSeek API Key。
- 未配置 API Key 时有明确错误提示。
